# Data Folder — Instructions

Place these two CSV files here before running the notebooks or apps:

1. `stroke_risk_dataset.csv` — the synthetic dataset (used by `notebooks/01_EDA_Synthetic_Data.ipynb`)

Neither file is included directly in this zip since they were already on your machine.
Once both files are here, delete this instructions file (`data/_INSTRUCTIONS.md`).
